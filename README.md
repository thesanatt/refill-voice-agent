# Prescription Refill Voice Agent

A voice agent that takes prescription refill requests over a (simulated) phone call and continues over (simulated) SMS if the call drops. Work in progress: the problem statement is in [docs/TAKE_HOME.md](docs/TAKE_HOME.md), kickoff clarifications in [docs/KICKOFF_NOTES.md](docs/KICKOFF_NOTES.md), design decisions in [docs/DECISIONS.md](docs/DECISIONS.md). Setup and run steps will follow.
