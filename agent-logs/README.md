# Coding-agent sessions

Every Claude Code session on this project, committed with the code. A hook exports each session to Markdown after every turn (`.claude/settings.json` runs `.claude/hooks/export_transcript.py`).

The hook could not read the transcript of the main build session, 3787a1f5, so that session was exported by hand with `/export` into `2026-11-05_session_3787a1f5.txt`. It covers the whole session, from the first research request to the shared test link. API keys are redacted in every log.
